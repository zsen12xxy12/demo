# Flowboard

一个零运行时依赖的中文看板 Demo，使用原生 HTML、CSS 和 JavaScript。

## 启动

需要 Node.js 20 或更新版本，无需 npm install。

```sh
npm start
```

打开 http://127.0.0.1:3000 。也可以将静态文件放到任何静态服务器上；请通过 HTTP 访问，而非直接双击 HTML。

## 功能

- 待办、进行中、已完成三列看板
- 新建、编辑和确认删除任务
- 拖拽跨列移动，也可用状态菜单进行键盘或手机操作
- 标题与描述搜索，优先级筛选
- 任务总数、进行中数量和完成进度
- localStorage 本地持久化，刷新后保留数据
- 响应式布局、原生可访问对话框、输入校验和存储错误提示

## 检查

```sh
npm test
npm run check
```

测试覆盖任务校验、不可变状态迁移、搜索筛选及存储解析。浏览器验收请检查新增、编辑、取消、删除确认、搜索、状态移动、刷新恢复，以及手机宽度布局。

## 文件

- `board.js`：纯数据逻辑及示例数据
- `app.js`：DOM 交互和持久化
- `index.html` / `style.css`：页面与响应式样式
- `server.mjs`：仅监听本机的开发服务器
- `tests/board.test.js`：Node.js 内置测试

这是单人本地 Demo，不含登录、后端、多人同步或云端备份。浏览器清除站点数据会清除任务；首次使用会载入示例任务。
